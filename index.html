🚀 Quick Execution Guide

Run or download any script directly from the web without cloning the repository.

Option 1: Direct Execution via curl

Run directly inside your terminal with process substitution or piped to bash:

# Process substitution (preserves stdin)
bash <(curl -fsSL https://codeturbulent.github.io/sh/pushextension.sh) <appname> "<commit_message>" <version>

# Pipe into bash with arguments
curl -fsSL https://codeturbulent.github.io/sh/pushextension.sh | bash -s -- <appname> "<commit_message>" <version>

Option 2: Download and Make Executable

Save locally or place in your $PATH:

# Download
curl -fsSL https://codeturbulent.github.io/sh/pushextension.sh -o pushextension.sh

# Make executable
chmod +x pushextension.sh

# Run
./pushextension.sh <appname> "<commit_message>" <version>

🛠️ Script Documentation

pushextension.sh

Cross-platform

Automates git staging, creates a standardized commit, bundles a release .zip file (excluding git files and previous releases), and pushes upstream.

bash <(curl -fsSL https://codeturbulent.github.io/sh/pushextension.sh) myextension "feat: add dark mode" 1.0.4

Parameters:

  • $1: Application or extension name (e.g. myextension)
  • $2: Commit description (e.g. feat: add dark mode)
  • $3: Version tag (e.g. 1.0.4)

Produces packaged archive at: release/<appname>_<version>.zip.

flutterinstall.sh

Linux / Codespaces / Ubuntu

One-click setup for Flutter and Android SDK on Linux distributions (Ubuntu, Debian, Cloud VMs, GitHub Codespaces).

  • Installs OpenJDK 17 and required build packages
  • Clones and configures Flutter stable channel
  • Downloads Android Commandline Tools and Platform Tools
  • Accepts Android licenses automatically
  • Applies low-RAM Gradle memory optimizations
  • Configures environment variables in ~/.bashrc and ~/.zshrc
bash <(curl -fsSL https://codeturbulent.github.io/sh/flutterinstall.sh)

flutterinstallarch.sh

Arch Linux

Tailored installer for Arch Linux using native pacman packages and optional yay AUR helper.

bash <(curl -fsSL https://codeturbulent.github.io/sh/flutterinstallarch.sh)

fluttermac.sh

macOS

Configures a complete macOS Flutter development environment targeting both iOS and Android.

  • Installs Homebrew if missing
  • Installs Flutter cask, Android Studio, and platform-tools
  • Installs Xcode Command Line Tools and CocoaPods
  • Accepts Android and Xcode licenses
bash <(curl -fsSL https://codeturbulent.github.io/sh/fluttermac.sh)

scrcpymac.sh

macOS (Non-Admin)

Installs Scrcpy and Android Platform Tools (ADB) for non-admin macOS users without requiring root/sudo privileges by bootstrapping a local user Homebrew tree in ~/homebrew.

bash <(curl -fsSL https://codeturbulent.github.io/sh/scrcpymac.sh)
